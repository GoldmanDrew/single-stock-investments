Section 5 – Corporate Governance and Management

 

Item 5.05Amendments to the Registrant’s Code of Ethics, or Waiver of a Provision of the Code of Ethics.

 

As a result of a review of the Code of Ethics for Senior Financial Officers, effective January 27, 2026, the Board of Trustees of Eversource Energy and the Boards of Directors of The Connecticut Light and Power Company, NSTAR Electric Company and Public Service Company of New Hampshire each approved and adopted an Amended and Restated Code of Ethics for Senior Financial Officers (the “Amended and Restated Code”). The Amended and Restated Code applies to each of the registrants named in this report. The Amended and Restated Code reflects changes in how public companies describe auditor oversight and compliance programs, and other clarifying, stylistic and non-substantive revisions. It also reflects current best practice by identifying the Audit Committee as having ongoing oversight responsibility for the Amended and Restated Code. The Amended and Restated Code does not materially change the responsibilities and obligations that applied previously and did not result in any waiver, explicit or implicit, of any provision of the previous Code for any of the registrants.

 

The summary of the Amended and Restated Code included in this Current Report on Form 8-K is qualified in its entirety by reference to the full text of the Amended and Restated Code. The Amended and Restated Code can be found on Eversource Energy’s website at www.eversource.com under “Investor Relations – Corporate Governance – Code of Ethics for Senior Financial Officers.” The contents of Eversource Energy’s website are not incorporated by reference in this report.
